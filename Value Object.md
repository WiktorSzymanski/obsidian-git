# Value Object
---
> Nie posiadają identyfikatorów i są fundamentalnie **definiowane przez ich atrybuty**. Zwykle opisują charakterystykę jakiejś rzeczy. Wynika z tego, że atrybuty są identyfikatorem *Value Object*-u. W momencie gdy zmienimy atrybuty stają się one innym obiektem.
> 
> *Value Object*-y są **stałe / niezmienne** *(ang. Immutable)*.
