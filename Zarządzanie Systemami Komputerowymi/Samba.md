# Samba
---

>to darmowa implementacja protokołów [[SMB]] (Server Message Block) i [[CIFS]] (Common Internet File System) dla systemów uniksowych. Oferuje możliwość współdzielenia plików i drukarek między komputerami z systemem Windows, macOS i innymi systemami uniksowymi. Dodatkowo samba może pełnić rolę kontrolera domeny, pozwalając na zarządzanie użytkownikami, grupami i zasadami bezpieczeństwa lokalnej sieci, wraz z integracją z [[Active Directory]]. Aby taką integrację osiągnąć wykorzystuje [[Winbind]].
